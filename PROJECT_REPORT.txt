PROJECT OVERVIEW
----------------
This is Sajed's personal portfolio website built with Astro + React. The project
started as a basic Astro site and evolved into a cinematic, scroll-driven
single-page experience with a custom animation engine, 3D WebGL background,
and a full observability layer.

  ─── Phase 8: Cinematic System Hardening ────────────────────────────────────

  Commit: 5e46ccc
  Time: 15:46

  Eight production hardening steps:
    1. Full ownership audit — all engine boundaries confirmed clean.
    2. ServicesScene translateY snap fix — replaced ternary snap (local<0.5 ?
       25 : -15) with continuous linear formula (30 - local*50).
    3. Removed 4 dev console.log() calls from CinematicOrchestrator. The 9s
       fallback console.warn was retained (signals real timing anomaly).
    4. Removed dead 'cinematic-boot-complete' CustomEvent from BootSystem —
       dispatched but never consumed.
    5. ScrollEngine and PointerEngine init wrapped in try/catch — either engine
       failure is non-fatal; the 9s fallback ensures the app always appears.
    6. ThreeCanvas resize listener made passive: { passive: true }.
    7. prefers-reduced-motion JS gate added to PointerEngine — reads
       matchMedia, tracks live changes, skips RAF subscriber notifications
       when active (CursorField, hero depth, CTA lift fully suppressed).
    8. Dead getAllScenes() export removed from SceneRegistry.

  ─── CinematicOrchestrator Introduced ───────────────────────────────────────

  Commit: 6ca83a3
  Time: 15:27

  Architecture refactor — replaced parallel implicit initialization with a
  single authority class enforcing strict startup ordering:

    1. SceneController registration
    2. ScrollEngine.initialize()  (Lenis created, stopped)
    3. PointerEngine.mount()      (passive mousemove + RAF)
    4. onDomReady()               (app DOM mounts behind loader)
    5. BootSystem.boot()          (cinematic status sequence)
    6. _triggerEntry()            (scroll unlocked, loader out, app in,
                                   cinematic-entry dispatched)

  App.tsx reduced to a single CinematicOrchestrator.run(callbacks) call.
  CinematicApp.tsx retired. No visual changes — architecture only.

  ─── Phase 9: Production Validation ─────────────────────────────────────────

  Commit: da822a1
  Time: 15:52

  Lifecycle hardening across all three engines:

  PointerEngine:
    - Fixed event listener leak: mousemove/mouseleave closures now stored as
      instance fields so removeEventListener actually works on unmount.
    - Delta-time normalized LERP: 1-(1-LERP_60)^(dt/16.667). At 30fps the
      pointer now converges at the same wall-clock rate as 60fps. dt clamped
      to 100ms (prevents tab-resume position jump).
    - _lastTime reset in unmount() for clean re-mount.

  ScrollEngine:
    - visibilitychange handler: calls lenis.stop() when tab hides, lenis.start()
      on return — prevents the large time-gap scroll jump on tab resume.
    - Listener reference stored for clean removeEventListener in destroy().
    - start() guards document.hidden — Lenis not started if tab is hidden at boot.
    - destroy() removes visibilitychange listener and resets _running.

  CinematicOrchestrator.cancel():
    - Now calls ScrollEngine.destroy() + PointerEngine.unmount() for full cleanup.
    - Resets _started = false — enables clean SPA back-navigation and React
      StrictMode second-mount cycle (previously caused blank screen on re-mount).

  ─── Phase 10: Dev-Only Observability Layer ──────────────────────────────────

  Commit: 53552eb
  Time: 16:01

  Two new files with zero production cost:

  src/core/observability/CinematicMonitor.ts
    Singleton collecting:
      - FPS (1s rolling + 5s rolling averages)
      - Frame spike detection (>20ms frames)
      - Scene transition log (last 50 transitions)
      - Engine health flags (scroll/pointer/boot complete)
      - Subscriber counts (memory growth indicators)
    All guarded by import.meta.env.DEV. Exposed as window.__cinematic in dev:
      .snapshot()  → full structured health object
      .history()   → last 50 scene transitions
      .fps()       → { avg1s, avg5s }
      .reset()     → clear accumulators
      .health()    → engine health flags

  src/core/observability/DebugOverlay.tsx
    Fixed React HUD (toggle: Ctrl+Shift+D) displaying:
      FPS (color-coded), frame spikes/worst frame, active scene, scroll %,
      pointer nx/ny, pointer active state, engine health flags, subscriber counts.
    Polls at 1Hz via setInterval (not RAF — zero cost when hidden).
    Fully absent from production bundle (tree-shaken at JSX render site).

  Engine instrumentation added (all DEV-only):
    - ScrollEngine: recordFrame() in RAF tick, health flags on lifecycle events
    - SceneController: recordSceneTransition() on state change, subscriber count
    - PointerEngine: mount/unmount flags, subscriber count, active state relay
    - BootSystem: setBootComplete(true) on successful boot

# Inquiry Log — Da Vinci Studio

Log every inquiry here. One entry per contact. Review monthly.  
Classification guide: see `GROWTH_SYSTEM.md Part I`.

---

## Log format

Copy this block for each new inquiry:

```
---
Date:        YYYY-MM-DD
From:        [name, company if given]
Email:       [email domain — not full address for privacy]
Source:      [how they found you: LinkedIn / direct / referral / search / unknown]
Type:        A / B / C / D
Score:       [clarity 1-3] + [seriousness 1-3] + [alignment 1-3] = [total /9]

Brief summary:
[One sentence: what they want, what sector, any budget signal]

Signals noted:
[Positive or negative signals — list format]

Action taken:
[Responded / Declined / Ignored / Pending]

Outcome:
[Project started / Discovery call / No response / Declined by client / Lost to price]

Notes:
[Anything that should inform a future messaging decision]
---
```

## Example entries

```
---
Date:        2026-07-14
From:        Sarah K., Aura Hospitality Group
Email:       @aurahospitality.ae
Source:      LinkedIn (clicked link from founder post)
Type:        A
Score:       3 + 3 + 3 = 9

Brief summary:
Boutique hotel group, 3 properties, needs full website redesign before Q3 opening.
Existing site is Squarespace, clearly frustrated with the template.

Signals noted:
+ Registered business email
+ Named competitor portfolio for reference
+ Asked about timeline, not price, in first message
+ Mentioned a previous agency that "didn't understand the brand"
- No explicit budget stated (but hospitality at this level implies range)

Action taken:
Responded same day. Proposed 20-minute discovery call.

Outcome:
Discovery call held. Project scope agreed. Proposal sent.

Notes:
Hospitality sector is high-alignment. "Didn't understand the brand" is a 
recurring phrase from good clients — worth noting as a positive signal pattern.
---
```

```
---
Date:        2026-07-22
```

## Monthly summary template

At the end of each month, add a summary block:

```
## [Month Year] Summary

Total inquiries:     __
Type A:             __ ( __%)
Type B:             __ ( __%)
Type C:             __ ( __%)
Type D:             __ ( __%)

Projects started:    __
Discovery calls:     __
Declined:            __

Most common source:  __
Highest quality source: __

Patterns noticed:
[Any recurring misalignment, recurring positive signal, or messaging implication]

Messaging action taken (if any):
[What changed and why — or "none"]
```

## Quarterly pattern review questions

Answer these at the end of each quarter:

1. What was the most common inquiry type (A/B/C/D)?
2. Which source produced the highest proportion of A/B inquiries?
3. What was the most common reason for C/D classification?
4. Did any pattern of C/D inquiries suggest a messaging problem?
5. What did A inquiries have in common? (Industry, referral source, language used)
6. Should any copy be refined based on this quarter's data?
7. Is the availability status accurate?
8. What is the approximate conversion rate (projects started / total inquiries)?

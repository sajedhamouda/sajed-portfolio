## General rules for all platforms

1. **"Da Vinci Studio" is the entity** — not "Sajed Hamouda freelancer." Build the studio brand, not the personal brand, as the primary identity. Sajed is the founder of the studio, not the product.

2. **Consistency beats cleverness** — use the same headline language across platforms. Platform algorithms reward consistency; audiences reward it with trust.

3. **Link to the portfolio everywhere** — `davincistudio.ae` should appear in every profile bio. Every social platform is a referral path to the primary platform.

4. **Update profiles when work is added** — a LinkedIn profile last updated two years ago signals stagnation. When a new project is added to the Work scene, update the Experience entry description within the same week.

5. **Do not maintain platforms you cannot maintain** — an inactive Behance with three projects from 2022 actively hurts the positioning. Either maintain it or remove the profile entirely.
